# Online Store Database

Учебный проект по дисциплине "Базы данных".

Предметная область проекта — интернет-магазин.

Цель проекта — спроектировать и реализовать базу данных для хранения информации о клиентах, товарах, заказах и оплатах.

Репозиторий содержит домашние задания по проектированию и реализации базы данных в PostgreSQL.

## Структура репозитория

- HW1 — проектирование базы данных и ER-диаграмма
- HW2 — реализация схемы базы данных в PostgreSQL
