## Запросы реляционной алгебры

### Запрос 1. Выборка и проекция
**Формулировка на естественном языке:**
Найти названия всех фильмов жанра 'Фантастика'.

**Запись на языке реляционной алгебры:**
π_title(σ_{genre='Fantasy'}(movies))

**Пояснение:**
1. Операция выборки (σ) отбирает строки из таблицы `movies`, где жанр равен 'Fantasy'.
2. Операция проекции (π) оставляет только столбец `title`.

---

### Запрос 2. Соединение отношений
**Формулировка на естественном языке:**
Вывести имя клиента и название фильма, на который он купил билет.

**Запись на языке реляционной алгебры:**
π_{name, title}(customers ⋈ tickets ⋈ sessions ⋈ movies)

**Пояснение:**
1. Операция соединения (⋈) связывает четыре таблицы по внешним ключам (customer_id, session_id, movie_id).
2. Операция проекции (π) оставляет только имя клиента (`name`) и название фильма (`title`).
